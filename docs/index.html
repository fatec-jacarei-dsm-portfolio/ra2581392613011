greener.exe _ ▢ ✕
LEVEL 02 · 2DSM – 2º Sem. 2026 ACADÊMICO

GreenER

Plataforma web desenvolvida pela equipe Green Stack na Fatec Jacareí para estimar o impacto ambiental de aplicações de software. O sistema coleta métricas de infraestrutura (CPU, memória, disco e rede), estima o consumo de energia e, com a intensidade de carbono da região do serviço, calcula as emissões de CO₂ equivalente (CO₂e).

Minha contribuição
  • Integração do backend com as APIs de métricas e de intensidade de carbono, com mocks locais e tratamento de erros e timeouts.
  • Autenticação com JWT: login, cadastro de usuários, limite de tentativas e proteção das rotas de coleta e do dashboard.
  • Persistência de serviços e coletas no PostgreSQL e rotina de coleta periódica das métricas.
  • Detecção de serviços indisponíveis, ativos sem métricas, incluídos e removidos.
  • Tela de ranking por energia e CO₂e com filtros, além de ajustes de responsividade mobile e acessibilidade.
  • Testes automatizados, ambiente com Docker Compose e documentação da API e do projeto.
  • TypeScript
  • Node.js
  • React
  • PostgreSQL
  • Docker
  • Figma
  • Git
